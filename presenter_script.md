# Presenter Script

## Opening

"Today I am going to show Collibra Data Marketplace as a mission storefront for trusted open source intelligence data products. The analyst's problem is familiar: public information is everywhere, but not every source is reliable, legally reusable, current, or appropriate for the mission. The demo is about speed with control."

## Scene 1: The Mission Need

Persona: Maya Chen, OSINT mission analyst.

Mission: Prepare a regional infrastructure disruption brief for leadership. Maya needs public-source event reports, source reliability context, and aggregated geospatial features. She has one hour.

Key message:

"The goal is not to collect everything. The goal is to find approved, explainable data products that can be used confidently."

## Scene 2: Marketplace Landing Page

Show curated collections:

- Crisis Monitoring Starter Kit
- Public Source Trust Framework
- Narrative and Media Signals
- Reference Data for Sanctions and Organizations

Talk track:

"The marketplace landing page is tailored to the analyst's role. Instead of starting with database names or system tables, Maya starts with mission-oriented products curated by data owners and stewards."

## Scene 3: Search and Discovery

Search phrase:

`infrastructure disruption public reports`

Open:

`Public Infrastructure Event Feed - Curated`

Show:

- Description
- Owner and steward
- Certification status
- Data quality score
- Refresh cadence
- Access method
- Related business terms
- Lineage

Talk track:

"This product packages public reports into a curated event feed. Notice the governance context: it tells Maya what the data means, where it came from, how current it is, what quality checks passed, and who owns it."

## Scene 4: Trust and Provenance

Open lineage or related assets.

Lineage story:

Public source registry -> ingestion jobs -> extraction and normalization -> deduplication -> human review queue -> curated event feed -> dashboard/notebook.

Talk track:

"For OSINT, provenance is not a nice-to-have. Analysts need to know whether a signal came from an official bulletin, a media report, or an unverified public post. Collibra gives that provenance a governed home."

## Scene 5: Compare Good Product vs. Risky Product

Open:

`Raw Public Web Mentions - Restricted`

Show:

- Not certified
- Lower trust score
- Privacy/legal review required
- Raw text restricted
- Retention limit
- No individual profiling caveat

Talk track:

"This is the moment that usually lands with agency teams. Collibra does not just help people find data; it helps them find the right version of data. Most analysts should use the curated aggregate, not raw public web mentions."

## Scene 6: Add to Basket

Add these products:

- Public Infrastructure Event Feed - Curated
- OSINT Source Registry
- Source Reliability Scorecard
- Geospatial Situation Features - Aggregated

Checkout details:

- Purpose: Regional infrastructure disruption brief for crisis response planning
- Duration: 30 days
- Use: Analytic reporting and dashboarding
- Restriction acknowledgement: No individual profiling; cite source caveats; use aggregated outputs for external sharing

Talk track:

"Maya can request a bundle of related products in one flow. The access request captures why she needs the data, for how long, and under what purpose."

## Scene 7: Steward Approval

Switch persona: Rafael Ortiz, data steward.

Show policy decisions:

- Curated public event feed: approve
- Aggregated geospatial features: approve
- Source registry: approve
- Reliability scorecard: approve for trained analysts
- Raw public web mentions: route to privacy/legal review or deny for this use case

Talk track:

"Approval is not just a manual yes/no. It is tied to classification, purpose, steward ownership, and handling caveats. This gives the agency a defensible audit trail."

## Scene 8: Close

Closing message:

"For the analyst, Collibra Data Marketplace reduces search time. For the steward, it enforces responsible access. For leadership, it makes intelligence products more explainable. The same platform supports discovery, trust, approval, reuse, and auditability."

## Five-Minute Executive Version

1. Search for `infrastructure disruption public reports`.
2. Open `Public Infrastructure Event Feed - Curated`.
3. Show trust indicators: certification, quality score, owner, refresh, lineage.
4. Open `Raw Public Web Mentions - Restricted` as a contrast.

7. Close on responsible, reusable OSINT.
